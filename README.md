# app-spotify-clone-udemy

Clone da **interface do Spotify** — exercício do curso Android da Udemy focado em reproduzir telas reais de um app conhecido.

## Objetivo

Treinar UI Android: navegação entre telas/abas, listas de músicas, ícones e paleta do app original.

## Tecnologias

- Kotlin
- AppCompat, CardView, ConstraintLayout, Material
- AGP 4.2.1 / Gradle 6.7.1

## Pré-requisitos

- **JDK 11**
- Android SDK

## Como rodar

```bash
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties   # macOS
./gradlew assembleDebug
```

Ou abrir no Android Studio e executar `MainActivity`.
